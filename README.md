## About the Project

VayuDrishti is a proposed National Weather Big Data Analytics Platform
designed to collect, process, verify and visualize real-time weather
information from multiple sources.

The platform combines weather data, citizen reports, websites,
public datasets and other sources to provide actionable weather-event
information through an interactive dashboard.

---

## Key Features

- Real-time weather data collection
- Citizen weather reports
- AI/NLP-based information extraction
- Fake report detection
- Duplicate report detection
- Source verification
- Automatic weather-event classification
- Trust Score for reports
- Multilingual and Hinglish support
- Interactive real-time dashboard
- Location-based weather event visualization

## Methodology

1. Collect weather posts, APIs and citizen reports.
2. Clean and process incoming data.
3. Extract location, time and event information.
4. Detect duplicate and potentially fake reports.
5. Generate a trust score.
6. Store verified information centrally.
7. Display weather events through the dashboard.

---

## Innovation

### Trust Score
Instead of simply marking a report as true or false,
VayuDrishti provides a graded credibility score.

### Cross-Modal Verification
Reports can be cross-checked using text, image metadata,
radar and satellite information.

### Hyperlocal & Multilingual
The platform is designed to handle Indian languages
and Hinglish/code-mixed content.

### Crowd as a Sensor Network
Citizen reports can help fill information gaps between
sparse weather stations.
